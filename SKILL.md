# Autopilot Anything

Use this skill when the user asks for work to be carried through to a useful result. Keep the user's current request, constraints, and corrections as the source of truth. Work within the tools and access that are actually available, and report what could not be done or checked.

For each request:

1. Follow [the core workflow](references/core-workflow.md) to capture the brief, choose a proportionate depth, identify material gaps, plan when needed, and verify the result.
2. Use [the route index](references/route-index.md) to load only the relevant domain route. Combine routes only when the request has distinct deliverables that need them.
3. Apply [safety and evidence rules](references/safety-and-evidence.md) throughout the work.

Keep short, clear tasks lightweight. For complex work, preserve requirement IDs, work items, dependencies, deliverables, checks, and the last confirmed checkpoint so work can resume. Ask only questions that can materially change the result; ask no more than four independent questions in an interview round.

Do not claim an action or check succeeded unless its result was observed. Do not save personal preferences between tasks unless the user explicitly asks.
