# 0003. Диспетчер доменных маршрутов с общим маршрутом

## Контекст

Исходный Autopilot ориентирован на программирование, а продукт должен принимать задачи в разных областях. Для кода, исследований, сбора информации, данных и файлов нужны разные методы и критерии качества; заранее перечислить все возможные области нельзя.

## Решение

Диспетчер определяет тип задачи и результата, сложность, риск и доступные инструменты, затем выбирает профильный маршрут. Для задач без специального профиля применяется общий маршрут, который честно описывает доступные действия и ограничения.

## Почему

Рассматривались сохранение одного кодового маршрута и единый общий процесс для всех областей. Первый исключает значительную часть целевых задач; второй не задаёт проверок, нужных конкретному виду результата. Профильные маршруты позволяют задать такие проверки, а общий маршрут сохраняет охват задач, для которых профиль ещё не описан.

## Последствия

Нужно поддерживать индекс маршрутов, профили и правила диспетчеризации. Общий маршрут должен оставаться полезным при отсутствии нужных инструментов, но не может обещать профильную проверку там, где её нет.
