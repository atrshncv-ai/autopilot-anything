Autopilot Anything — переносимый скилл для самых разных запросов: от небольшого изменения файла до сложного многоэтапного проекта. Он ищет недостающие детали, способные повлиять на результат, а затем подбирает глубину процесса и проверок под конкретную задачу.

## Быстрый старт · Codex

Установите скилл для своей учётной записи Codex:

```sh
SKILLS_DIR="${CODEX_HOME:-$HOME/.codex}/skills"
mkdir -p "$SKILLS_DIR"
git clone https://github.com/atrshncv-ai/autopilot-anything.git "$SKILLS_DIR/autopilot-anything"
```

Если Codex уже открыт, перезапустите его. Затем вызовите скилл:

```text
$autopilot-anything Подготовь презентацию на шесть слайдов со сравнением трёх вариантов для моего проекта.
```

В Codex его также можно выбрать через `/skills`. Для Claude Code и Cursor установите его в пользовательскую папку скиллов и вызывайте как `/autopilot-anything`; подробности — в разделе [Установка для других агентов](#установка-для-других-агентов).

## Какие задачи он решает

| Маршрут | Пример запроса | Проверки по типу результата |
|---|---|---|
| Код и программы | Создать небольшое приложение или исправить функцию | Запустить подходящие проверки проекта и просмотреть изменения |
| Научное исследование | Проверить гипотезу и подготовить черновик статьи | Проверить источники, отделить факты от выводов и обозначить ограничения |
| Поиск информации | Сравнить продукты, правила или текущие события | Проверить актуальные источники и связать выводы с доказательствами |
| Анализ данных | Найти причины изменений или построить график | Сохранить исходные данные, объяснить метод и сделать расчёты воспроизводимыми |
| Презентации | Создать доклад для конкретной аудитории | Проверить отрендеренные слайды и содержание, и оформление |
| Документы и файлы | Подготовить отчёт, таблицу или файлы проекта | Проверить содержание и формат; рендерить, если важна вёрстка |
| Остальные задачи | Составить план поездки, процесса или выбора | Использовать доступные инструменты, раскрывать допущения и проверять возможное |

## Один процесс — глубина под задачу

Скилл сохраняет исходный бриф, реестр требований, прогресс и точку возобновления, а в конце сверяет результат с тем, что вы просили. Простые задачи с низким риском можно сразу довести до результата. Для крупных или рискованных задач предусмотрены более глубокое интервью, план и проверки, подходящие выходным материалам. Скилл ищет пропущенные требования, задаёт вопросы о тех, что способны изменить результат, и умеет продолжить прерванную работу.

Для каждого прогона создаётся живой read-only дашборд (dashboard), если это поддерживает среда, и автономный HTML-снимок (snapshot). На панели видны этапы, решения, требования, рабочие единицы, проверки и события; управлять работой или подтверждать действия через неё нельзя. [Жизненный цикл дашборда](references/dashboard.md).

## Установка для других агентов

Этот репозиторий уже является полной папкой скилла. Храните `SKILL.md`, `references/` и `scripts/` вместе.

| Агент | Вызов | Инструкция |
|---|---|---|
| Codex | `$autopilot-anything` или выбор через `/skills` | [Установка, обновление и проверка](platforms/codex.md) |
| Claude Code | `/autopilot-anything` | [Установка, обновление и проверка](platforms/claude-code.md) |
| Cursor | Выберите `autopilot-anything` в меню Agent `/` | [Установка, обновление и проверка](platforms/cursor.md) |

Для Codex есть отдельная инструкция по установке. Руководства Claude Code и Cursor соответствуют документированным механизмам скиллов, но в этих средах не проходили runtime-проверку. Остальные агенты могут использовать переносимый `SKILL.md` и справочные материалы по принципу best-effort.

## Статус совместимости

| Платформа | Что проверено |
|---|---|
| Codex | Установка и обнаружение нативным селектором проверены в Codex CLI 0.142.5 21 октября 2026 года. Поведенческие проверки остаются отложенными: модель завершилась ошибкой до ответа, поскольку доступные ID моделей были отклонены. [Полный протокол](compatibility/codex.md). |
| Claude Code | Инструкция учитывает документированный механизм скиллов; runtime-проверки не проводились. |
| Cursor | Инструкция учитывает документированный механизм скиллов; runtime-проверки не проводились. |

Результаты относятся к проверенной среде и не гарантируют работу во всех версиях, учётных записях и настройках. Проверка структуры пакета не заменяет проверку в самом агенте.

## Инструменты, риск и доказательства

Пакет содержит инструкции, справочные материалы, трекер прогресса и валидатор. Он сам по себе не добавляет браузер, редактор файлов, коннекторы, учётные данные или другие инструменты: возможности зависят от разрешений и инструментов конкретной среды. Для физических задач скилл может подготовить план и материалы, но не заявляет, что выполнил физические шаги. В высокорисковых областях он может давать рекомендации с опорой на доказательства, обозначая неопределённость и границы. Перед отправкой, публикацией, оплатой, покупкой, удалением и другими существенными внешними действиями требуется подтверждение.
