# 0001. Отдельный публичный пакет

## Контекст

Autopilot Anything — публичная адаптация навыка, исходно предназначенного для программирования. Родительская папка сборки содержит журнал `.autopilot`, а исходный репозиторий включает другие навыки.

## Решение

Пакет Autopilot Anything собирается отдельно в `autopilot-anything/`; журналы сборки и несвязанные навыки в него не входят. При распространении сохраняются MIT-лицензия, уведомление об авторстве и указание на производную адаптацию.

## Почему

Рассматривалась публикация адаптации внутри исходного сборника. Этот вариант втягивает в публичный пакет несвязанные навыки и смешивает продуктовую границу с журналом текущей сборки; отдельный пакет соответствует выбранному публичному продукту.

## Последствия

Для отдельного пакета нужно поддерживать собственные материалы установки и выпуска. Вместе с ним придётся переносить лицензию и атрибуцию исходника; `.autopilot` остаётся только в родительской сборке.
