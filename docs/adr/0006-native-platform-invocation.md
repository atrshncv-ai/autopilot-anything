# 0006. Нативный вызов в каждой платформе

## Контекст

Первоначальная формулировка подразумевала общий явный вызов `/autopilot-anything`. D01 зафиксировал, что Codex предлагает вызов скилла через `$skill-name` или выбор через `/skills`, но не команду `/skill-name`.

## Решение

Скилл сохраняет единое имя `autopilot-anything`, а явный вызов соответствует интерфейсу платформы: Codex `$autopilot-anything` или выбор через `/skills`, Claude Code и Cursor `/autopilot-anything`.

## Почему

Рассматривалась одна и та же slash-команда на всех платформах. Она не соответствует описанному механизму явного вызова Codex; нативные способы дают пользователю правильный путь к одному и тому же скиллу.

## Последствия

Инструкции установки должны показывать имя скилла отдельно от команды вызова. Точный способ вызова следует поддерживать в адаптере каждой платформы.
