# 0002. Переносимое ядро и адаптеры платформ

## Контекст

Скилл предназначен для Codex, Claude Code и Cursor. Их способы установки, вызова и доступ к инструментам различаются, поэтому общий формат не гарантирует одинакового поведения.

## Решение

Общие этапы, инварианты и критерии готовности принадлежат переносимому ядру. Установку, обнаружение, нативный вызов и ограничения конкретной среды описывает адаптер платформы.

## Почему

Рассматривались полные копии скилла для каждой платформы и реализация только для одной среды. Копии дублировали бы общие правила и могли бы разойтись; вариант одной среды не покрывает целевые платформы. Адаптеры сохраняют общую семантику и отдельно описывают реальные возможности каждой среды.

## Последствия

Нужно поддерживать платформенные инструкции и указывать ограничения каждой среды. Live-проверка Codex не означает, что Claude Code или Cursor также проверены.
