# Autopilot Anything

Autopilot Anything — один переносимый скилл для выполнения задач от краткого брифа до проверенного результата. Он выбирает подходящую глубину работы, подключает нужный маршрут и сообщает, что не удалось выполнить или проверить.

Целевой публичный репозиторий пакета — [atrshncv-ai/autopilot-anything](https://github.com/atrshncv-ai/autopilot-anything). Корень репозитория — это папка скилла; в репозитории находятся только адаптация Autopilot Anything и необходимые материалы.

Скилл содержит инструкции, справочные материалы и проверку структуры пакета. Он сам по себе не добавляет браузер, доступ к файлам, MCP-коннекторы, сервисы или учётные данные. Доступные действия зависят от инструментов и разрешений конкретной среды; другие платформы поддерживаются по принципу best-effort.

## Дашборд прогона

Для каждого прогона трекер хранит состояние проекта в `.autopilot/anything/<run-id>/`. Скилл запускает трекер из установленной папки пакета и открывает локальную read-only панель, если платформа поддерживает localhost и фоновый процесс. На случай, если это недоступно, сохраняется отдельный `snapshot.html`. Панель показывает этапы, гейты, требования, рабочие единицы, проверки, время ожидания и последние события; менять состояние через неё нельзя. [Жизненный цикл и команды дашборда](references/dashboard.md).

## Что сохранено и заменено

Сохранены исходный бриф дословно, реестр требований, адаптивное интервью, прогресс и точка возобновления, а также итоговая приёмка по исходному брифу. Кодовые тикеты по зонам файлов, волны реализации и подсчёт тестов заменены единицами работ по маршруту и проверками, подходящими результату: источники и доказательства для исследования, воспроизводимые расчёты для данных, рендер документов и слайдов, проверки проекта для кода. Три уровня процесса определяются сложностью; риск и необратимость оцениваются отдельно и могут усиливать меры защиты на любом уровне.

Склонируйте репозиторий в пользовательскую папку скиллов нужной платформы или добавьте его как submodule проекта. Корень репозитория уже является полной папкой скилла — храните `SKILL.md`, `references/` и `scripts/` вместе. Точные команды установки, обновления, удаления и безопасной ручной проверки приведены в руководствах платформ:

- **Codex CLI / IDE:** пользовательский путь `$HOME/.agents/skills/autopilot-anything/`; проектный — `<repo>/.agents/skills/autopilot-anything/`. Вызов: `$autopilot-anything` или выбор через `/skills`.
- **Claude Code:** `~/.claude/skills/autopilot-anything/` или `<repo>/.claude/skills/autopilot-anything/`. Вызов: `/autopilot-anything`.
- **Cursor:** `$HOME/.agents/skills/autopilot-anything/` или проектный `<repo>/.agents/skills/autopilot-anything/` / `<repo>/.cursor/skills/autopilot-anything/`. В Agent чате введите `/` и выберите скилл.

Точные шаги установки, обновления, удаления и ручной проверки: [Codex](platforms/codex.md), [Claude Code](platforms/claude-code.md), [Cursor](platforms/cursor.md). Синтаксис вызова различается по платформам.

Полный текст MIT и сведения о происхождении адаптации находятся в [LICENSE](LICENSE) и [ATTRIBUTION.md](ATTRIBUTION.md). Другие навыки исходной коллекции сюда не входят.

## Статус совместимости

Полная живая проверка предусмотрена только для Codex. 21 октября 2026 года в Codex CLI 0.142.5 подтвердились установка в изолированный проект и обнаружение скилла, но проверки выполнения остановились до ответа модели: доступные ID моделей были отклонены. Поведенческие сценарии остаются непроверенными, поэтому этот запуск не подтверждает полную совместимость с Codex. Руководства для Claude Code и Cursor адаптированы по аналогии с документированными механизмами скиллов и не проверялись в этих средах. Подробности — в [протоколе проверки Codex](compatibility/codex.md).
